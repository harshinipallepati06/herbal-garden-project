# 🌿 Herbal Garden - Ayurvedic Recommendation System

## 📌 Overview
A web-based application that provides Ayurvedic remedies for respiratory diseases and suggests nearby doctors based on user location.

## 🚀 Features
- 🌿 Disease-based herbal recommendations
- 📍 Location-based doctor suggestions
- 📞 Appointment booking (call integration)
- 🧠 Severity-based logic
- 🎨 Modern UI with Bootstrap

## 🛠 Tech Stack
- Python (Flask)
- HTML, CSS, Bootstrap
- Pandas
- Excel datasets

## 📊 Dataset
- Medicinal plants dataset
- Doctors dataset (location-based filtering)

## 💡 Future Scope
- AI-based disease prediction
- Google Maps integration
- User login system
